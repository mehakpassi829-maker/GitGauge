Help & Documentation

    
Getting started, methodology, and frequently asked questions.

  


  

    
Getting Started

    

      

        GitGauge analyses public GitHub profiles using six deterministic intelligence engines.
        No account is required. Enter any public GitHub username in the top search bar and click Analyze.
        Results appear within seconds.
      

    

  


  

    

      

        What data does GitGauge use?
        
      

      

        GitGauge fetches only public repository data from the GitHub API. This includes repository metadata, push timestamps, descriptions, stargazer counts, fork counts, and primary language. No private repositories, emails, or personal information are accessed.
      

    

    

      

        How are scores calculated?
        
      

      

        Each intelligence engine applies a fixed set of deterministic rules to the fetched repository data. Scores are weighted sums of sub-metrics: Commit (18%), Architecture (20%), Algorithm (17%), Documentation (15%), Collaboration (15%), Developer Growth (15%). No machine learning is used.
      

    

    

      

        What is the Developer Intelligence Score?
        
      

      

        The Developer Intelligence Score is a composite score (0–100) derived from all six engine scores. Grades: A+ (85+), A (70+), B+ (55+), B (40+), C (below 40). It is not a hiring prediction.
      

    

    

      

        Why are some metrics estimated?
        
      

      

        The GitHub public API returns repository-level metadata, not individual commit events. Some metrics (like commit frequency) are estimated from repository age and push timestamps. This is a known limitation of the bounded public snapshot approach.
      

    

    

      

        Can I analyze private repositories?
        
      

      

        No. GitGauge only analyses public repositories. Private repositories are neither accessible nor included in any score.
      

    

    

      

        Is GitGauge suitable for hiring decisions?
        
      

      

        No. GitGauge measures specific GitHub activity patterns using public data only. It is not a comprehensive evaluation of developer skill, experience, or hiring fitness. The score should be treated as one data point, not a verdict.
      

    

    

      

        What is Guest Mode?
        
      

      

        Guest Mode allows anyone to run a full profile analysis without creating an account. Analysis history is kept only for the current browser session. Rate limits may apply based on GitHub API quotas.
